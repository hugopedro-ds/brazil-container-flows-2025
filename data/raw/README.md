# Raw data (not included)

The ANTAQ files used in this project are not stored in the repository: they are large and publicly available. Save them in this folder with exactly the names below.

## 1. Panel extracts, 2025 (notebook 02)

**Source:** ANTAQ — Painel do Estatístico Aquaviário, calendar year 2025. The custom reports sheet ("8. Relatórios Personalizados – Movimentação") lets you choose the columns, filter the year and export:
https://aquarela.antaq.gov.br/single/?appid=2b370bbc-6a27-4e2e-8c43-56f1732c19f8&sheet=816b5cf4-46df-407d-b1e8-85f24d1c3015&opt=currsel%2Cctxmenu

The link opens the panel with whatever filters are active — set the year to 2025 before exporting. The original ANTAQ column names used for each file are listed in notebook 02, Bloco 2 (the renaming map from Portuguese to English).

- antaq_2025_cargo.xlsx
- antaq_2025_cargo_ports.xlsx
- antaq_2025_port_calls.xlsx
- antaq_2025_stoppages.xlsx
- antaq_2025_panel_gr23.xlsx

Notebook 02 checks that all five files are present before running and lists any that are missing.

## 2. Bulk download, 2024 and 2025 (notebooks 04–15)

**Source:** ANTAQ's bulk-download page (https://web3.antaq.gov.br/ea/sense/download.html#pt). Choose the year, download the zip files below, unzip them and rename the text file inside as shown. The files used here were generated by ANTAQ on 17 July 2026.

Occupancy and stoppage files are used only by notebook 15. From the "Tabelas de Cadastro" section of the same page, `MercadoriaConteinerizada.txt` (saved as `antaq_mercadorias_conteiner.txt`) adds official commodity names to notebook 11; without it, the notebook shows codes only.

The two cargo files are about 450 MB each; the notebooks read only the columns they need.

The same page has a data dictionary ("Download metadados (dicionário)"), useful for column definitions. The key one for this project: `FlagMCOperacaoCarga = 1` marks cargo counted as port throughput, which excludes restows.

**Consistency with the panel:** for 2025, 9,999 container calls are in both sources with an identical TEU figure per call. The bulk files add 85 calls at Paranaguá in February (missing from the panel export); eight calls added after the bulk extraction appear only in the panel. Notebook 05 runs this check.

ANTAQ updates its database regularly, so files downloaded later may differ slightly from the figures in this project.
